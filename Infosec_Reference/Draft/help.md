# Panduan dan Template Referensi Penulis

Halaman ini merupakan struktur acuan (*authoring scaffold*) untuk menyusun bagian referensi baru. Ganti simbol `%` dengan topik/subjek yang sedang didokumentasikan.

Referensi Emoji: [Daftar Contekan Emoji](https://www.webpagefx.com/tools/emoji-cheat-sheet/)

```markdown
Bantuan/Referensi


Gagasan Utama:

Apa itu % ?

Di mana saya bisa belajar lebih lanjut tentang % ?

Referensi untuk % ?

Contoh penerapan % ?

Tutorial yang membahas % 

Tulisan teknis / Writeup tentang %  


* **Umum (General)**
* **Dasar / Pemula (101)**
* **Artikel/Makalah/Presentasi/Writeup**
* **Alat & Perkakas (Tools)**
* **Lain-lain (Miscellaneous)**
```
